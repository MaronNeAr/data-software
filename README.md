# data-software

个人软件工程与数据技术知识库，涵盖从底层系统到上层应用的多个技术领域。

## 目录结构

| 目录 | 内容 |
|------|------|
| [java](java/) | Java 基础、JVM、并发编程、Spring 框架、SSM、Gradle 等 |
| [go](go/) | Go 语言快速上手、核心原理、与 Java 对比学习 |
| [big-data](big-data/) | 大数据生态：Hadoop、Spark、Flink、ClickHouse、Iceberg、Trino、Hive 等 |
| [ai](ai/) | AI 与机器学习：大模型基础、多模态、推荐系统、RLHF、提示词工程、AI Agent |
| [middle-ware](middle-ware/) | 中间件：Redis、Nginx、Netty、Kubernetes、Docker、消息队列等 |
| [framework](framework/) | 架构与设计：设计模式、微服务、分布式架构、数据中台、凤凰架构等 |
| [business](business/) | 商业与技术交叉：计算广告等 |
| [hpc](hpc/) | 高性能计算：C++、并行程序设计 |
| [linux](linux/) | Linux 内核源码学习 |

## 主要内容

- **Java**: JVM 原理、并发编程实战、Spring 源码、Arthas 调试
- **Go**: 语法快速上手、核心原理（GMP、GC、Channel 等）
- **大数据**: Spark 内核、Flink 原理、ClickHouse、Iceberg、Trino 等主流引擎
- **AI**: 大模型训练（SFT、RLHF）、多模态、推荐系统、AI Agent
- **中间件**: Redis 设计与实现、Kubernetes、Netty、分布式消息
- **架构**: 数据密集型应用设计、微服务、分布式架构、数据中台
- **高性能**: C++ Modern Effective、并行计算
- **Linux**: 内核源码分析
